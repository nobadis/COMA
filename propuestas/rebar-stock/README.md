# COMA Rebar Stock · propuesta y demo

Control de stock automático de rebar leído desde el puente grúa (carretilla como opción).

- `COMA-Rebar-Stock-Resumen.pdf` — resumen (ES, 5 págs.).
- `COMA-Rebar-Stock-Propuesta-tecnico-comercial.pdf` — propuesta técnico-comercial (ES).
- `COMA-Rebar-Stock-Demo.mp4` — vídeo demo (EN, ~2 min, efectos de sonido, sin música).

Fuentes: `video/demo.html` (escenas animadas; abierto en el navegador se reproduce sin sonido),
`video/sound.py` (efectos a partir de `cues.json`), `pdf/*.html` + `pdf/doc.css` + `pdf/diagrams/`.
Regenerar todo: `bash propuestas/rebar-stock/build.sh` (tras `npm install` en la raíz).
